# Eddalore legal pages

Published by MakeSense Embedded Systems. Served with GitHub Pages:

- Privacy policy: https://jannieduiwel.github.io/eddalore-legal/privacy.html
- Terms of use: https://jannieduiwel.github.io/eddalore-legal/terms.html
- Open-source notices: https://jannieduiwel.github.io/eddalore-legal/licenses.html

Plain HTML with no external requests. Edit the files and push to `main` to update the pages.

Eddalore has no accounts, so unlike `makesense-legal` there is no delete-account page: the policy explains that nothing is collected and how to clear what the app keeps on the phone.
